# Codeyzer Screen — Windows releases

[**screen.codeyzer.com**](https://screen.codeyzer.com) · Turn your Android tablet into a low-latency extra display for your PC.

This repository hosts the release binaries of the **Windows app** (the source code is private). Every version is listed with its release notes on the [Releases](../../releases) page.

## Download (always the latest)

| Platform | File |
|---|---|
| Windows 10 (version 2004 or later) / Windows 11 · x64 | [`Codeyzer-Screen-Setup.exe`](../../releases/latest/download/Codeyzer-Screen-Setup.exe) |

> The `releases/latest/download/Codeyzer-Screen-Setup.exe` link **always points to the newest version** (the file name stays the same). The version number and notes are on each release's own page.

## Install

Run `Codeyzer-Screen-Setup.exe` and approve the administrator prompt; the installer sets up its drivers itself. Connect the tablet to the PC with a USB cable; the first time, Windows asks for approval once.

**Support:** support@codeyzer.com · **Privacy:** https://screen.codeyzer.com/privacy

# Codeyzer Screen — Windows Sürümleri

[**screen.codeyzer.com**](https://screen.codeyzer.com) · Android tabletinizi düşük gecikmeyle bilgisayarınızın ek ekranı yapın.

Bu depo **Windows uygulamasının** yayın binary'lerini barındırır (kaynak kod özeldir). Her sürüm [Releases](../../releases) sayfasında sürüm notlarıyla listelenir.

## İndir (her zaman en güncel)

| Platform | Dosya |
|---|---|
| Windows 10 (sürüm 2004 veya üstü) / Windows 11 · x64 | [`Codeyzer-Screen-Setup.exe`](../../releases/latest/download/Codeyzer-Screen-Setup.exe) |
